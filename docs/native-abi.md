# Native ABI 合同 v1

MVP0 只暴露低风险探针。所有导出必须满足：

1. 导出名使用 `Native_` 前缀，使用 `extern "C"` 和稳定标量/指针类型。
2. UTF-16 字符串由调用方分配，函数不得保存调用方指针。
3. 返回 `0` 表示成功；`-1` 表示参数无效；`-2` 表示缓冲区不足；后续错误码集中在本文档登记。
4. 回调只在调用线程执行；未显式支持取消的 API 必须同步快速返回。
5. 每个导出必须有 FFI 冒烟测试覆盖成功、参数无效、缓冲区不足。

## Native_Version

- 原型：`int Native_Version(wchar_t* buffer, int length)`
- 行为：写入 NUL 结尾 UTF-16 版本串。
- 成功返回 `0`。
