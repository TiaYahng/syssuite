# 清理规则 Schema

清理规则是磁盘清理器的可审计输入，规则只负责“发现”，执行器仍必须经过路径白名单与备份校验。

## 字段

- `id`: 稳定规则 ID。
- `target`: 目标目录模板；支持 `{root}`、Windows 环境变量以及 `*` 目录通配符。
- `env`: 可选环境变量名数组，目标路径中的 `%NAME%` 会展开。
- `regex`: 可选正则，匹配完整文件路径；未填写表示目标下全部文件。
- `exclude`: 可选正则数组，任一命中即排除。
- `minAgeDays`: 最小文件年龄，最后写入时间小于该值的文件不进入结果。
- `level`: `safe` / `caution` / `risky`，对应 UI 的风险等级。

规则默认只读发现，不允许通过规则扩大受保护系统路径。任何执行都必须再次经过 ProtectedPaths/路径白名单校验。
